Why is it fast?文件在两台设备之间直接跑，No Server Relay、不排队、不限速。速度上限 = 你们双方的上行带宽或局域网带宽。
Is it safe?Connect由 DTLS End-to-End Encryption，Code只用于牵线；服务器只帮忙交换Connect地址，看不到文件内容。
What if it can't connect?The program tries multiple lines automatically; if both are under strict NATs, TURN relays can be used as a fallback (see guide).
